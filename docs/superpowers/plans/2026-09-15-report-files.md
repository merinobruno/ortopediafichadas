# Static XLSX and PDF report exports

Capture an authenticated, immutable read-transaction snapshot using the same applied report filters and shared reporting calculations. Require both civil dates (maximum 366 inclusive days). SQL scopes employee/date/site/status selection and caps rows before dependent break/overtime reads; name matching retains the existing JavaScript case-insensitive semantics. Reject oversized results rather than truncate. CSV remains unchanged.

Portable runtime ExcelJS/PDFKit renderers receive the snapshot only, never a database. XLSX has four distinct sheets (summary/employees/sites/detail), literal strings, numeric metrics, UTC Date cells and separate BA entry dates. PDF landscape A4 has measured wrapped rows/repeated headings/page numbers. Unknown net hours remain blank and approved overtime stays separate. Authenticated no-store attachment responses only.

Worker limits: 10,000 detail rows XLSX / 2,000 PDF, 20 MiB output, 30 seconds, two global workers and one per account; heap caps and disconnect/deadline cleanup.
